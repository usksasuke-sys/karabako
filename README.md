# 空の箱

新米刑事として、夜明けの現場から調べるブラウザゲームです。答えは、現場と話と資料の中にあります。この README に筋書きは書いていません。

## ブラウザで遊ぶ

https://usksasuke-sys.github.io/karabako/

## 手元で開く

`index.html` をダブルクリックして開きます。進行は、そのブラウザの中に残ります。

## タブレットで試す

手順は `タブレットでの試し方.txt` にまとめてあります。同じWi-Fiで開く方法と、フォルダをコピーして開く方法があります。

## 公開するとき

指示があるまで、Netlify には上げません。上げるときは、このフォルダを Netlify のサイトに置きます。ビルドコマンドは不要です。公開ディレクトリはフォルダの直下です。

`脚本.md` は作者用です。遊ぶ人の手元には置かないでください。
